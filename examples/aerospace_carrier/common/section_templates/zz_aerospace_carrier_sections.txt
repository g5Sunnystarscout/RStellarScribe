# ------------------------------------------------------------------------------------
# Section templates for the aerospace carrier.
#
# Section fields verified against vanilla military sections
# (common/section_templates/corvette.txt, battleship.txt, ...):
#   key / ship_size / fits_on_slot / should_draw_components / entity / icon
#   component_slot = { name template locatorname }   -> weapon and hangar slots
#   large_utility_slots / medium_utility_slots / small_utility_slots   -> shields & armour
#   aux_utility_slots                                                  -> aux components
#
# The first version of this file was copied verbatim from the vanilla military arkship, and
# that was wrong for a hull the player outfits in the designer: the arkship section carries
# ONLY weapon slots (477 hangars/turrets/PD in vanilla terms, zero utility), because an
# arkship's shields and armour come from its starbase modules instead. The result was a
# designer screen with a single weapon layout and no component slots at all - including no
# aux slot, so the Muster Platform (size = aux) could not be fitted.
#
# The entity is still the military arkship hull, so only the locators that entity actually
# has may be used: hangar_01/02, medium_turret_01..04, pd_turret_01..04.
# Utility and aux slots are counts and need no locator.
#
# Three layouts are offered so the designer has a real choice in the "mid" slot.
# ------------------------------------------------------------------------------------
